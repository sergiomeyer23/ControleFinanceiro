# ControleFinanceiro
Sistema simples de controle financeiro em Java.

## O que ele faz?
- Cadastra receitas e despesas
- Calcula saldo total
- Lista movimentações

## Tecnologias usadas
- Java

## Como executar
1. Tenha o JDK instalado
2. Compile: `javac ControleFinancas.java`
3. Execute: `java ControleFinancas`
